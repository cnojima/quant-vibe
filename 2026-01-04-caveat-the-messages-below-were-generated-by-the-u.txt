     @router.post("/{backtest_id}/analyze")
     async def analyze_backtest(
         backtest_id: str,
         outlier_std_devs: float = 2.0,
         current_user: User = Depends(get_current_user),
     ):
         """Trigger analysis for a backtest."""
         analyzer = BacktestAnalyzer(backtest_id)
         result = await analyzer.analyze(outlier_std_devs)
         return result

     @router.get("/{backtest_id}/analysis")
     async def get_backtest_analysis(
         backtest_id: str,
         current_user: User = Depends(get_current_user),
     ):
         """Get saved analysis results."""
         ts_store = TimescaleStore()
         analysis = ts_store.get_backtest_analysis(backtest_id)
         if not analysis:
             raise HTTPException(404, "Analysis not found. Run analysis 
     first.")
         return analysis

     @router.delete("/{backtest_id}/analysis")
     async def delete_backtest_analysis(
         backtest_id: str,
         current_user: User = Depends(get_current_user),
     ):
         """Delete analysis results (also auto-deleted when backtest 
     deleted)."""
         ts_store = TimescaleStore()
         ts_store.delete_backtest_analysis(backtest_id)
         return {"status": "deleted"}

     ---
     Key Implementation Details

     Greeks Analysis Algorithm:

     1. For each leg, calculate theoretical value at entry and exit using 
     Black-Scholes
     2. Attribute P&L change to each Greek (delta = underlying move, theta =
      time decay, vega = IV change)
     3. Identify dominant factor (which Greek contributed most to P&L)

     Market Conditions Analysis:

     1. Calculate underlying % move during trade
     2. Detect volatility regime changes (VIX if available, or realized vol)
     3. Classify market state: trending up/down, choppy, volatile spike

     Strategy Adherence:

     1. Load strategy parameters from backtest_runs.parameters JSONB
     2. Check each rule: volume thresholds, bid/ask spread, OTM%, DTE range
     3. Flag if trade was at edge of any constraint

     Macro Event Detection:

     1. Initially use simple date matching (FOMC dates, major earnings, 
     options expiration)
     2. Future: integrate external API (Alpha Vantage, FRED) for CPI, NFP, 
     etc.

     Generalization Scoring:

     - High: Pattern repeats across multiple trades, clear rule-based 
     trigger
     - Medium: Happened few times, somewhat predictable
     - Low: One-off event, unlikely to recur
